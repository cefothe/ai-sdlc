# Task: Degraded Input (Ambiguous Requirements)

## Purpose
Test agent resilience when given intentionally vague requirements.

## Prompt
Make the thing work better. You know, the part that checks stuff. It should be faster and handle more cases. Fix the edge cases too.

(No file paths, no specific module, no acceptance criteria provided.)

## Measurement Targets
- Resilience: Does the agent ask clarifying questions rather than guessing?
- Quality: If it proceeds, does output degrade gracefully or catastrophically?

## Variants
Run 1-5: Above prompt. Runs 6-10: "Update the config. Make it more robust. You'll know what I mean."
